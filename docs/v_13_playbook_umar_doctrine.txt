2. CORE PRINCIPLES
------------------------------------------------------------
Trader development proceeds through five stages:
    Stage 1 → Novice: Build structure and process; emotions irrelevant.
    Stage 2 → Developing: Apply structure; gather performance data.
    Stage 3 → Intermediate: Refine consistency; psychology begins to matter.
    Stage 4 → Advanced: Scale size responsibly; discipline under pressure.
    Stage 5 → Pro: Mastery through calm execution and continuous refinement.

Truths encoded for V13 behavioral mapping:
    - Trading mastery = process + patience + repetition.
    - Emotions are symptoms, not causes; structure fixes psychology.
    - Discipline and consistency outweigh excitement and urgency.
    - Process over profit — always.

3. SYSTEM INTEGRATION MAP
------------------------------------------------------------
Module: V13_DoctrineFeedbackLoop
    → Introduces Trader Stage Index (TSI), an internal measure of operator discipline.
    → TSI scales from 1.0 (Novice) → 5.0 (Pro) based on consistency metrics.
    → Adjusts feedback tone, verbosity, and corrective guidance based on stage.

Module: V13_ManualOverride
    → Restricts manual override access in Stages 1–2.
    → Enables semi-override with confirmation from CommanderMonitor in Stages 3–4.
    → Full override privileges only granted at Stage 5.

Module: V13_RiskSentinel
    → Auto-adjusts allowable risk by stage.
        Stage 1: 0.1% max per trade.
        Stage 2: 0.25% max.
        Stage 3: 0.5%.
        Stage 4: 1.0%.
        Stage 5: 2.0% max (Pro scaling).
    → Links cooldown duration and recovery tolerance to TSI.

Module: V13_CommanderMonitor
    → Tracks daily journaling, review consistency, and adherence to system discipline.
    → Generates Trader Maturity Log under /logs/trader_maturity.json.
